# 课程设计原始要求摘录

本文档整理《操作系统》课程设计参考内容与要求，用于追溯 `docs/PRD.md` 和 `docs/TECH.md` 的需求来源。

## 1. 总体体系

OS 课程设计采用“基础必做 + 自由扩展提升”两级体系，突出操作系统核心原理、系统级编程能力与工程实践能力培养。

## 2. 基础必做部分

基础必做部分占 70%，面向操作系统核心知识与基本实现能力训练，所有学生必须独立完成。重点通过模拟实现与系统编程实践，加深对操作系统基本机制、资源管理方法与并发控制思想的理解。

### 2.1 处理机调度

模拟实现典型处理机调度算法，示例包括：

- 先来先服务 FCFS。
- 短作业优先 SJF。
- 时间片轮转 RR。
- 优先级调度。

要求：

- 支持动态输入进程参数。
- 能够输出进程运行顺序、周转时间等结果。
- 能够分析不同调度算法的特点与性能差异。

### 2.2 内存管理

模拟实现动态分区管理与页面置换机制，示例包括：

- FIFO 页面置换。
- LRU 页面置换。
- 首次适应 FF。
- 最佳适应 BF。

要求：

- 能够展示内存分配与回收过程。
- 能够统计缺页次数与缺页率。
- 理解分页、分区与虚拟存储等思想。

### 2.3 进程同步与并发控制

利用线程与同步机制实现经典同步问题：

- 生产者-消费者问题。
- 读者-写者问题。
- 哲学家进餐问题。

要求：

- 使用多线程模拟并发执行。
- 正确使用互斥锁、信号量等同步机制。
- 能够避免死锁与数据竞争问题。

### 2.4 文件系统

设计实现文件系统或目录管理模块。

要求：

- 支持文件创建、读写、删除基本操作。
- 实现空闲空间管理。
- 理解文件组织与存储管理机制。

### 2.5 基础部分总体要求

- 熟悉 Linux 开发环境与基本工具链。
- 掌握 C 语言系统级程序设计方法。
- 具备程序调试、测试与代码规范能力。
- 能够完成实验分析与实验报告撰写。

## 3. 自由扩展提升部分

自由扩展提升部分占 30%。在完成基础部分的前提下，鼓励学生结合个人兴趣、技术基础与工程能力，进一步开展综合性、探索性与创新性实践。

可选方向包括：

### 3.1 Linux 内核与系统编程

- Linux 内核模块开发。
- 字符设备驱动设计。
- `/proc` 或 `/sys` 接口开发。

### 3.2 调度与性能优化

- 调度算法改进与优化。
- 实时调度机制研究。
- 系统性能测试与分析。
- 并发性能优化实验。

### 3.3 国产操作系统实践

- openEuler 系统实验。
- HarmonyOS 开源版实践。
- 国产基础软件环境适配与测试。

### 3.4 嵌入式与实时操作系统

- ARM 平台操作系统实验。
- uC/OS-II 或 FreeRTOS 实践。
- 多任务与实时调度实验。

### 3.5 系统创新与综合设计

- 微型操作系统设计。
- 简易内核实现。
- 大模型驱动的智能操作系统原型。
- 自学习型的智能操作系统原型。
- 编译器与操作系统协同实验。
- 综合系统软件项目开发。

### 3.6 拓展部分总体要求

- 鼓励自主选题与创新实现。
- 强调系统设计与工程实践能力。
- 鼓励性能优化与跨平台实践。
- 支持小组协作与综合项目开发。
- 鼓励结合国产基础软件生态开展探索性研究。

## 4. 提交要求

- 完成提交时间：2026 年 6 月 11 日。
- 提交形式：报告 Word 文件或 PDF 文件。
- 报告必须包含代码 URL 和访问方式说明。
- 代码通过 GitHub 或类似平台托管。
- 报告中必须清晰指明代码 URL 及其访问方式。
